FLATICON® WEB APP — VERCEL READY

Project type: Static HTML/CSS/JS
Entry point: index.html
Assets: ./assets/

Deploy with Vercel:
1. Upload this project to a GitHub repository.
2. In Vercel, choose Add New Project.
3. Import the GitHub repository.
4. Framework Preset: Other.
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Deploy.

Important:
- Keep index.html and the assets folder in the repository root.
- Keep assets/product-video.mp4 in the assets folder.
- If the video exceeds the hosting provider's file limits, host the MP4 separately and update the <video> source.
